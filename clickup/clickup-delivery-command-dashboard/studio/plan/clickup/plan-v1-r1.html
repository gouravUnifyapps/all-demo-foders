Assumptions the plan is built on

  • intent proposed as both (the outcome, then how): one hood beat after the lean-forward beat; the owner sets it at G2.
  • scope is one app covering every ask, led by the portfolio dashboard, the executive summary and Delivery Copilot (G1 question 1, recommended option).
  • 18 fictional projects around the BRD's six sample customers; the headline counts read like the BRD's portfolio from the Weekly metric rows (G1 question 8).
  • the phone view is a responsive layout of the same code app shown in a phone frame (G1 question 9).
  • integrations show seeded status with one Sync failed row; the one live external step is the weekly summary email through the existing Gmail connection (G1 questions 10 and 11).
  • customers never see internal health (G1 question 5); the timeline is not editable from the phone (G1 question 4); region shows as a labelled tag, never colour alone (G1 question 6).
  • brand colour #5F55EE (hue 244) from clickup.com's --ProductScreen-CustomStatus-Primary; the sample was ambiguous and the profile takes the recommended one.
  • typeface Inter, the body face of clickup.com, with tabular figures, Noto Sans JP for Japanese, IBM Plex Mono kept for eyebrows (open question 13).
  • the app's sign-in, forgot and reset password are the tenant's own pages a PRIVATE code app opens with (open question 14).
  • roles are a persona switcher in the profile menu with a seeded roles grid; no tenant roles are made (open question 15).
  • documents open in an in-app viewer of the text the record holds; no file is uploaded.
  • customer logos on project cards and in the portal are circles holding the customer's initials, since the customers are invented.
  • German and Japanese portal text is drafted by Studio for the client to review.
  • the Copilot's working stages are shown by the app while the call runs (Reading projects, Checking risks, Writing answer).
  • Light is the default theme with the dark tokens live; Appearance in the profile menu switches it.
  • The AI agent's model is Nebula's recommendation (profile standing answer).
  • Release: publish and deploy on the tenant without asking; visibility PRIVATE (profile).
